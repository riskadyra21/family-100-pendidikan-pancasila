# Family 100 — Pendidikan Pancasila Kelas IX

Game kuis kelas gaya **Family 100** untuk mata pelajaran Pendidikan Pancasila, tema **Hak dan Kewajiban Warga Negara**.

Satu file HTML (`index.html`) — tanpa server, tanpa instalasi. Tinggal buka di browser.

**▶ Mainkan di sini: https://family-100-pendidikan-pancasila.vercel.app**

## Fitur

- Papan jawaban flip yang terbuka satu per satu lengkap dengan poinnya
- Panel skor 2 tim + penanda kesalahan (❌)
- Panel operator untuk guru: buka jawaban, beri ❌, pindah giliran, soal berikutnya
- **Editor soal berbentuk form isian**: tinggal ketik soal, jawaban, dan poinnya — tanpa format khusus; kata kunci pencocokan dibuat otomatis
- **Mata pelajaran, kelas, dan tema bisa diganti** langsung dari panel edit, tersimpan otomatis di browser masing-masing guru
- Musik latar dan efek suara bawaan (Web Audio)
- Layar kemenangan + kembang api untuk tim pemenang

## Cara pakai

1. Buka aplikasinya di browser (proyektor/Chromebook/HP).
2. Klik **Mulai Musik** bila ingin musik latar.
3. Baca soal, biarkan tim menebak — operator membuka jawaban yang benar dari panel.
4. Untuk mengganti soal: buka menu **Edit Soal**, tulis soal dengan format yang dicontohkan di sana, lalu simpan.
